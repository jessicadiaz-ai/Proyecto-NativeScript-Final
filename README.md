# Proyecto NativeScript Final

Este proyecto contiene la implementación de los 10 puntos requeridos en la rúbrica de NativeScript.

## Puntos Implementados

1. **Firebase Init & Token**: Inicialización del plugin de Firebase y obtención de token (`app/app.component.ts`).
2. **Notificaciones Push & Toast**: Recepción de notificaciones y muestra mediante Toast (`app/app.component.ts`).
3. **Social Share (Texto)**: Compartir mensajes de texto mediante el plugin (`app/components/share.component.ts`).
4. **Social Share (Imagen)**: Compartir imágenes mediante el plugin (`app/components/share.component.ts`).
5. **Cámara**: Captura de fotografías utilizando la cámara del dispositivo (`app/components/share.component.ts`).
6. **Integración Cámara + Social Share**: Conversión de Asset a ImageSource y envío a redes (`app/components/share.component.ts`).
7. **Google Maps SDK**: Inicialización y despliegue del mapa (`app/components/map.component.ts`).
8. **Marker en Google Maps**: Creación y configuración de un marcador con coordenadas (`app/components/map.component.ts`).
9. **Pruebas Jasmine para Redux**: Suite de pruebas unitarias validando un reducer de Redux (`app/tests/reducer.spec.ts`).
10. **Karma JUnit Reporter**: Configuración de reportes XML en el archivo de Karma (`karma.conf.js`).
